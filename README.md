# PersonaOS

Operating system based on Persona 5 videogame style. 

Persona 5 is a jrpg that uses a lot of abstract shapes and silhouettes and colors with sharp contrasts.
Everything is bright red, white, or black. There is also thick black outlines and a cat character called Morgana.

I copied that style by using a font on Reddit by KanjiPlaysInc.
I also used this website: https://bennettfeely.com/clippy/ to make the polygons shapes in html.

I read the tutorial but incorporated my chosen style.

The apps I have so far include:

Bear and Bird: Read and write notes about bears and birds.
Backgrounds: Customize the desktop background with Persona 5 backgrounds.
Morgana Clicker: Click on Morgana to increase the counter.
Calendar: Look at dates. 
Browser: Search things up on Wikipedia.
Paint: Draw Morgana
Message: Send me messages via email through this app.
